## 📖 عن اللعبة

لعبة تفاعلية تختبر قدرتك على تخمين الأمثال العربية الشعبية، الحكم، الآيات والأبيات الشعرية من خلال صور SVG مرسومة خصيصاً لكل لغز. حلّ محل الإيموجي المحدود بمجموعة موسعة من الأيقونات المعبّرة عن السياق الإسلامي والتراثي العربي.

## ✨ المميزات

- 🎯 **153 لغزاً متنوعاً** من الأمثال، الحكم، الشعر، والآيات
- 🖼️ **أكثر من 200 أيقونة SVG** بأسلوب موحّد، مجمّعة في ملف sprite واحد
- 📊 **3 مستويات صعوبة** × **5 فئات** — كل تركيبة مضمونة العدد
- ⏳ **تحدي اليوم**: 10 أسئلة ثابتة لجميع اللاعبين، ويُستأنف إن أغلقت الصفحة
- 📓 **دفتر الأمثال**: سجل دائم لكل لغز حللته
- 🔥 **سلسلة الإجابات**: ×1.5 عند 3 صحيحة متتالية، ×2 عند 5
- ⏱️ **مؤقت اختياري** بمكافأة سرعة
- 💾 **استكمال الجلسة** مع تحقق كامل من ملف الحفظ
- 🌙 **الوضع الليلي** يتبع تفضيل النظام افتراضياً
- 📲 **PWA** تعمل بالكامل بدون إنترنت
- ♿ **إمكانية وصول**: تكبير مسموح، احترام `prefers-reduced-motion`، مؤشرات تركيز واضحة
- 🔊 **تحكم بمستوى الصوت** إضافةً إلى الكتم
- 🔤 **الصور تُقرأ بترتيبها** — اللغز جملة رمزية لا مجموعة صور

## 🚀 التشغيل

اللعبة تستخدم **ES Modules**، وهذه محظورة على بروتوكول `file://` في كل المتصفحات
بسبب سياسة CORS. لذا **لا بد من خادم محلي** — فتح `index.html` مباشرة يعطي صفحة بيضاء.

```bash
npm start
# أو
python3 -m http.server 8000
# أو
npx serve
```

ثم افتح `http://localhost:8000`.

## 🧪 الاختبارات

```bash
npm test
```

تغطي التطبيع العربي ومطابقة الإجابات وسلامة قاعدة الأسئلة (أيقونات مفقودة،
إجابات مكررة، تصادم بين إجابتين، تلميحات تكشف الإجابة، فئات بلا أسئلة كافية).

## 🛠️ البناء

مكتبة الأيقونات تُولَّد من ملف مركزي، ثم تُجمَّع في sprite واحد:

```bash
npm run build:icons    # يولّد assets/images/*.svg
npm run build:sprite   # يجمّعها في assets/sprite.svg
```

> ⚠️ عدّلت أي أيقونة؟ شغّل `npm run build:sprite` — يوجد فحص في CI يرفض
> أي انحراف بين الـsprite وملفات المصدر.

## 🖼️ مكتبة الأيقونات

- viewBox موحّد `0 0 24 24`، أسلوب مستوحى من Lucide
- كل الأيقونات تستخدم `currentColor`، فتتبع لون الواجهة والوضع الليلي تلقائياً
- تُعرض عبر `<svg><use>` من sprite مُحقن في المستند — لو تعذّر تحميله ترجع اللعبة
  تلقائياً إلى `<img>` من `assets/images/`
- بعض المسارات مقتبسة من [Lucide Icons](https://lucide.dev) (ISC License) مع رسوم
  خاصة للأيقونات التراثية والإسلامية (الكعبة، المسجد، المصحف، السبحة، العقال،
  الغترة، الدلة، السيف العربي، النخلة، الجمل المحمّل، الفارس، الراية، إلخ)

## 🎮 طريقة اللعب

1. **أول زيارة**: لغز تعريفي واحد يشرح الآلية بالممارسة
2. **اختر النمط**: كلاسيكي أو تحدي اليوم
3. **اضغط زر التشغيل** — أو افتح «خيارات اللعب» لضبط الصعوبة والفئة والمؤقت
4. **اقرأ الصور بترتيبها** من اليمين لليسار كأنها جملة — الترتيب جزء من اللغز
5. **اكتب إجابتك** (لا حاجة للتشكيل، والأخطاء الإملائية البسيطة مقبولة)
6. **استخدم التلميحات** — 5 للجولة كاملة، 3 كحد أقصى لكل لغز
7. **حافظ على سلسلتك** للنقاط المضاعفة

> 💡 **استكمال الجلسة**: إن أغلقت اللعبة في منتصفها ستجد شريط الاستكمال عند العودة.
>
> 📓 **دفتر الأمثال**: كل لغز تحله يُفتح في الدفتر ويبقى محفوظاً.

## 📊 نظام النقاط

| المستوى | النقاط الأساسية | خصم التلميح |
|---------|-----------------|-------------|
| سهل | 10 نقاط | -3 لكل تلميح |
| متوسط | 20 نقطة | -3 لكل تلميح |
| صعب | 30 نقطة | -3 لكل تلميح |

- **الحد الأدنى**: 5 نقاط لكل إجابة صحيحة
- **انتقال المستوى**: كل 5 إجابات صحيحة، ويرفع الصعوبة درجة واحدة فوق اختيارك كحد أقصى
- **مكافأة السلسلة**: ×1.5 عند 3 متتالية، ×2 عند 5+
- **مكافأة السرعة**: +5 نقاط للإجابة في أول 10 ثوانٍ (وضع المؤقت)
- **التلميحات**: 5 للجولة كاملة (لا لكل سؤال)
- **التخطي**: مجاني مرتين في الجولة، ثم يكلّف حياة

## 🛠️ التقنيات المستخدمة

- HTML5 و CSS3 (Flexbox, Grid, CSS Variables, خصائص منطقية للـRTL)
- JavaScript ES6+ بصيغة Modules — **بدون أي مكتبات خارجية ولا اعتماديات وقت تشغيل**
- LocalStorage عبر محوّل آمن (يعمل حتى لو كان التخزين محجوباً)
- Web Share API، Service Worker + Web App Manifest، Canvas API
- خط Tajawal مستضاف ذاتياً — لا اتصال بأي خدمة خارجية
